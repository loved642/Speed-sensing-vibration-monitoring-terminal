# 实验方法与工程调试记录

整理日期：2026-11-02。用于技术报告中的实验方法、问题定位与心得体会。

## 1. 实验目的与证据来源

目标是在PYNQ-Z2上实现可复现的振动采集、帧计算、测速与PS读取链路，区分数值错误、总线错误、电气问题与机械实验差异。

早期故障现象采用开发者提供的项目经历；最终处理方法结合当前源码、已有修复记录、仿真日志及发布报告核对。现有代码能说明修复后的结构，不能单独复原每次早期故障的全部条件。未保留完整波形或日志的旧版耗时、资源峰值和具体故障数值不列为最终性能。

最终配置：Vivado 2025.2；PYNQ-Z2 / XC7Z020CLG400-1；PL 100 MHz；ADXL345 **I2C**；800 Hz / 1024点；20槽整周平均测速；1:48减速电机。早期SPI调试为方案演进记录，文件adxl345_spi.v保留旧名，当前实现为adxl345_i2c。

## 2. 分层验证流程

语法检查 → 模块仿真 → 独立数值对照 → 综合/实现/时序 → 无运动系统检查 → 传感器与测速 → 有限帧实验 → 独立运行评估。

每次只改变一个条件，并保存输入、配置、预期、输出和判断依据。先读一个寄存器，再引入完整采集；不能用某层通过替代后续层的验证。

| 层次 | 可自证的检查 | 合理结论 |
|---|---|---|
| 传感器 | DEVID=0xE5、配置成功、采样计数进展 | 地址与初始化链路工作；不证明连续读取对应独立转换 |
| FFT | DC、奇偶bin、双音、非整频、噪声；独立NumPy参考 | 数值与频点顺序在用例范围内符合约定 |
| 测速 | 给定时钟、脉冲间隔与槽数，计算预期RPM；测试首沿/停转/重启 | 周期与单位换算正确；不等于实物绝对RPM校准 |
| AXI | AW/W不同先后、背压、字节写、频谱地址、快照一致性 | 事务接收与数据发布符合约定 |
| 实物 | 固定装配；明确标签、实测RPM、run_id与质量字段 | 支持该安装批次的比较，不能自动外推跨安装性能 |

## 3. RTL与数值调试

| 现象 | 定位及根因 | 修复与最终核验 |
|---|---|---|
| 乘法后幅值异常、接近零 | 检查运算数、表达式上下文、有符号性、结果宽度与截断位置 | 显式声明乘积和加减中间量。当前26×16位旋转乘积为42位，26位平方结果为52位；以数值参考核验 |
| 函数返回值取位引起语法错误 | 早期Verilog写法/工具模式不接受直接索引函数调用结果 | 先赋给具名中间信号再索引，使位宽明确并通过xvlog |
| multi-driven net | 同一寄存器被多个时序过程驱动 | 明确单一驱动归属，合并相关状态/输出更新；综合和DRC检查 |
| RAM读出错拍、FFT错位 | 同步RAM/ROM及非阻塞赋值有寄存延迟 | 设址、等待、取样分状态，按实际流水对齐操作数与旋转因子 |
| 内存资源异常增长 | 访问方式要求同时多次写入，超出目标RAM端口模式 | 蝶形两次写回分拍、同步读取ROM并检查推断报告；ram_style只是提示，不是映射保证 |
| 实现时序负裕量 | 加窗乘法、复乘与加减或频点换算组合路径过长 | 拆分乘法、累加、舍入/换算流水，保留失败报告，对最终实现检查setup及hold |
| 峰值频点或输出数目错误 | FFT输入排列、蝶形与输出序号约定不一致；单音检查覆盖不足 | 最终DIT在加载时reverse(ld)，输出自然顺序k=0..511。12帧/6144个bin逐点比较通过 |

### 位宽表述修正

不能写成“signed16×signed16在Verilog里一定只产生16位”。表达式的有效位宽还受上下文、操作数扩展和最终赋值/截断影响。应结合IEEE 1364表达式定宽规则检查具体代码，显式设置足够宽且符号正确的乘积与加减信号，再验证舍入、缩放和饱和。单独摘出max(L(i),L(j))不足以证明某段程序一定截成16位。

### FFT排列与BRAM表述修正

不能把“DIT输出一定要位反转”写成最终实现。当前代码在输入加载时位反转，输出为自然频点。也不能把添加ram_style="block"等同于全部工作RAM落入BRAM；历史修复记录明确存在工作RAM映射为分布式RAM的构建。最终只报告实现报告中的整体资源。

## 4. 接口与上板调试

| 现象 | 定位及根因 | 修复与结论 |
|---|---|---|
| 寄存器读写停滞 | 检查AW/W独立握手及缓存、读返回流水与背压；错误假设地址和数据同拍可能丢失事务 | 分别锁存AW/W，凑齐后执行；频谱读考虑同步RAM延迟。不能只凭等待两个VALID同时出现就断言必然死锁 |
| CTRL写入或频谱读区错误 | 对照总线地址、低位偏移、拼接宽度和频谱边界 | 最终用低16位译码，频谱为0x1000≤偏移<0x1800；不能把所有地址只截低12位 |
| SPI阶段字节错位 | 从机记录主机字节，逐沿核对SPI模式和移位顺序 | 修正输出/移位时机；检查模型是否覆盖命令。该经验属于早期SPI原型，最终采集采用I2C |
| SPI长期无响应，模组接口与预期不一致 | 开发者通过断电测量确认SDO接地配置 | 结合CS及模块实际连接使用I2C，SDO低对应0x53地址。这本身不代表芯片损坏；不能用电源强拉接地引脚 |
| I2C地址读为0xFF等异常 | 引脚级模型逐沿检查START到首个数据位，识别多余时钟边沿 | 修正SCL/SDA状态顺序；检查ACK、重复START、时钟拉伸、卡总线恢复与有限重试 |
| 默认Python找不到pynq或Overlay加载失败 | 核对实际Python环境、设备权限与运行时变量 | 本部署脚本启用pynq-venv，设置XILINX_XRT=/usr，由sudo调用；驱动兼容phys_addr/base_address |
| MMIO事务挂住，用户态超时无效 | 外设/互连不返回响应时，用户态timeout不一定能解除硬件访问 | 先做最小只读检查，保留串口与可控复位/断电恢复路径；不宣称Python超时能恢复AXI总线 |

AXI的32位地址不要求一律只使用“低几位”。应按互连映射与外设地址窗口设计；本项目低16位可容纳寄存器和0x1000起始频谱区。有效握手是VALID与READY在时钟边沿同时成立，响应在背压期间必须保持。

## 5. 实验可信度与机械安装

传感器的DEVID、初始化和采样进度应先于电机实验。ADXL345上电处于待机，配置输出率、格式和测量使能后才开始采样。当前I2C按本地节拍轮询，读取成功和计数进展不证明每次读取都对应新转换，DATA_READY同步仍可作为改进方向。

将电机、传感器及线缆固定，换轮前停机；电机独立5 V供电并共地。固定方式、电源和线缆变化可能改变振动和噪声分布，不能仅凭某次幅值变化指定唯一原因。

保留原始质量字段和无效帧，评估时按用途筛选。转速基线需要完整帧、测速有效、稳态以及无溢出/削顶；orders还需要频带有效。**并非所有分析都要求所有质量位为1，也不是所有无效帧都禁止落盘。**例如最终flags=0x07可供broadband分析，但缺少bit3，不能用于orders。

50%与70%是PWM占空比，不是50/70 RPM。800 Hz和1024点对应1.28 s、0.78125 Hz分辨率；60 RPM时单帧仅约1.28圈。低速1x/2x当前频带可能重叠，应显式拒绝无效阶次特征。

训练/验证/测试按完整run_id隔离。仅run_id不同仍不足以证明独立拆装或跨日期泛化；某批数据用于观察和选特征后，应视为开发数据。早期RPM=0的数据可保留作诊断，不能投入分转速校准；早期识别失败也要留档。

## 6. 工程化与复现

- 用脚本构建PS+PL Overlay，并将twiddle.mem与hann.mem注册为Memory Initialization Files，确认综合子进程能解析readmemh。只把文件放在某个工作目录不是通用解决方案。
- 保存时序、资源、ROM和IOBUF检查，保留最终配对bit/hwh及SHA-256。纯PL试验性放宽NSTD-1/UCIO-1的做法不作为最终PYNQ交付流程。
- Tcl按行提取PS预设参数，避免大括号与正则词法相互干扰。
- 建议用Git追踪源码、脚本与文档，发布时固定版本；已完成的是源码包、哈希清单和原始数据归档，尚未建立公开GitHub仓库，不能声称已经发布。
- 板卡日期错误时保留原始文件名并说明，不能事后伪造采集时间。后续采集前校时并记录时区。
- 保留串口恢复通道，复位后重新检查端口；网络IP属于现场配置，不写成板卡固定出厂值。

## 7. 最终量化结果与未验证项

采用同一发布版报告：100 MHz，WNS +0.903 ns，TNS 0，WHS +0.008 ns；LUT 5264，FF 4291，BRAM 3，DSP 16。不混用早期约2000 LUT、另一版5062 LUT或未经当前版本复核的517 µs运算时延。1.28 s是采集帧长度，不是FFT计算延迟。

2026-11-02打包源码复验：I2C 6271项通过，FFT 12帧/6144个正频率bin与NumPy通过，测速与AXI/PWM/watchdog通过，主机8项与候选RMS工具8项测试通过。既有参考比较最大幅值误差约0.116原始计数，是该定点参考测试结果，不是传感器绝对精度。

最终12次运行600帧均flags=0x07，I2C=0且无记录丢帧、漏读或编号间断。新轮70%Y轴RMS均值+34.9%属于描述性比较；没有独立识别准确率、外部RPM校准或物理报警时延结论。

## 8. 心得

单音峰值命中只验证了一个局部条件。扩展到边界输入与独立参考后，才能检查频点顺序、缩放、输出完整性与完成脉冲。仿真模型也须核对协议，不应先验认定其无误。

电气、逻辑与实验统计分别需要证据：DEVID和握手检查不能替代机械重复性，数据质量通过也不保证正常/偏心可分。先确认固定、供电、采样与实测转速，再评价算法，能减少反复采集却无法解释结果的情况。

大模型协作应包含自我纠错：根据源码修正位宽、DIT排列、地址窗口和质量位表述；保留失败结果与方案更改，不把未经测量的推断写成完成指标。
